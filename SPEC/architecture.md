# Arquitetura

- Reutilize componentes existentes antes de criar novas abstrações.
- Mantenha domínio, aplicação e infraestrutura separados quando o projeto já usa essa divisão.
- Mudanças de contrato, persistência ou dependência externa devem aparecer no plano.
- Uma mudança arquitetural exige decisão explícita e registro da justificativa.
