# Definition of Done

- Critérios de aceite atendidos e rastreados para testes.
- Build, lint, testes e análises de segurança aprovados.
- Diff revisado por agente revisor e pelo ABE conforme risco.
- PR documenta solução, testes, riscos, migração e rollback.
- Homologação validada antes de produção.
- Saúde técnica e resultado esperado observados após o deploy.
